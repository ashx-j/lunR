**Hazards.**
- **High, `packages/ai/src/api/anthropic-messages.ts:828,873–893`:** transport is selected by a substring in the secret, not credential type. An external connection cannot safely pass through today's `apiKey` result.
- **High, `packages/ai/src/auth/resolve.ts:29–57` and `packages/ai/src/models.ts:417–458`:** stored OAuth still refreshes and flows to direct HTTP. Removing only the login UI would leave existing accounts on that route.
- **Medium, `packages/ai/src/providers/anthropic.ts:13–16` and `packages/ai/src/env-api-keys.ts:69–71`:** ambient OAuth tokens outrank API keys. The migration gate must cover both files.
- **Medium, `packages/ai/src/auth/oauth/anthropic.ts:30–33,134–168`:** manual login still requires the fixed localhost callback port; a busy port prevents even manual entry. Callback host can differ from the fixed `localhost` redirect URI.
- **Medium, `packages/ai/src/auth/oauth/anthropic.ts:178–225`:** token-exchange errors include the full server response body. Keep response bodies and credentials out of diagnostics when changing the flow.
- **Medium, `packages/coding-agent/package.json:24–35` and `packages/ai/package.json:50–55`:** packages ship `dist`; adding a Python worker under source or vendor alone will not put it in a published install.
